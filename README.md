# Hack The Box

This repository contains writeups, problem files, and notes for various Hack The Box contents.

## Directory Structure

### 📂 Challenges
Collections of Hack The Box Challenges, primarily focusing on **Forensic** challenges.
- Writeups and analysis for forensic artifacts.
- Solved challenge files and scripts.

### 💻 Machines
Walkthroughs and notes for **Hack The Box Machines**.
- Steps taken to compromise target machines.
- Exploitation scripts and gathered loot.

### 🕵️ Sherlocks
Investigations for **HTB Sherlocks**, which are defensive security labs.
- Incident response analysis.
- Blue team investigation notes and timeline reconstruction.
